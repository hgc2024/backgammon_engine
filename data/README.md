# Independent Bear-off Data

These databases were generated by this project's MIT-licensed implementation
from the standard rules of backgammon. They are not copies or conversions of
GNU Backgammon databases.

## One-sided 6-point/15-checker database

File: `bearoff-one-sided-6x15-v2.npz`

- States: 54,264
- Completion-time and first-checker-off distributions
- Preferred successor for all 21 dice classes
- Policy: minimum expected rolls, then earliest completion CDF
- SHA-256: `6E83E3E715AF06DF51E1CD4D3581AABF4ECC4A368765FC02B87B671AC963BA66`

Regenerate with:

```console
python -m src.generate_bearoff
```

## Exact two-sided 6-point/6-checker database

File: `bearoff-two-sided-6x6-v1.npz`

- One-sided states: 924
- Position pairs: 853,776
- Value: exact cubeless probability that the player on roll wins
- Policy: equity-optimal play for every dice outcome
- SHA-256: `A7AC70709555DE31A8CAE2AB857630263C12D12B9108293EEE2A6004DF8F878B`

Regenerate with:

```console
python -m src.generate_two_sided_bearoff
```

The two-sided database is game-theoretically exact apart from float32
serialization. The one-sided policy is exact for its stated objective, but it
is an approximation when an opponent-specific move would trade mean bear-off
time against variance.
